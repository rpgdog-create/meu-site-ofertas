Adicionar Produtos

📦 Amazon — Lote (recomendado)

  1. Clicar "📦 Amazon Promos" no admin
  2. Abrir terminal, colar e rodar o comando
  3. Aguardar Chromium terminar (~1 min) → copia pro clipboard
  4. Voltar ao admin → colar na textarea → Importar → Adicionar todos → Salvar no site

📦 Amazon — Individual

  1. Clicar "AM Clear"
  2. Na página do produto, clicar "AM Copy" (repetir em cada produto)
  3. Clicar "AM Export" → colar no admin → Importar → Salvar

📦 Amazon — Busca (Batch)

  1. Clicar "AM Clear"
  2. Abre busca na Amazon → clicar "AM Batch"
  3. Clicar "AM Export" → colar no admin → Importar → Salvar

⚠️ Categoria vem vazia — aplicar no admin. Não funciona em bestsellers/goldbox.

🛒 Mercado Livre

  1. Abrir 2 abas do ML (intercalando subdomínios)
  2. Clicar "ML Clear" nas duas abas
  3. Barra de Afiliados → Compartilhar → clicar "ML Copy" em cada produto
  4. Clicar "ML Export" na aba A → copiar
  5. Clicar "ML Export" na aba B → copiar
  6. Colar os dois no admin → Importar → Adicionar todos → Salvar

🛍️ Shopee

Colar o link do produto na textarea → Importar → Salvar. (API ainda pendente.)

Remover Produtos

Individual: clicar 🗑️ no card → Salvar no site.

Todos: botão "Remover todos" → Salvar no site.

Automático (Sync): botão "Sync" no admin → remove produtos que retornam 404/410/403. Roda sozinho a cada 6h.

Cupons

Adicionar / Atualizar (3 cliques)

  1. Clicar "🎟️ Cupons ML" no admin → abre ML em nova aba
  2. Clicar bookmarklet "ML Cupons" → copia JSON pro clipboard
  3. Voltar ao admin → clicar "🎟️ Importar Cupons" → salva direto

Como funciona no site

Chip "🎟️ Cupons" no header e busca por "cupons". O botão "Resgatar →" abre o site filtrado (categoria + marketplace) — o usuário vê produtos com seu link de afiliado e compra → comissão.

Dica

Se o cupom for de uma categoria específica, preencher o campo categoria no JSON — o link é gerado automaticamente e abre o site já filtrado.

Categorias

37 categorias fixas + customizadas (criadas via "➕ Gerenciar categorias" no admin).

  • Criar: input + botão "Criar"
  • Renomear: ✏️ → atualiza em todos os itens
  • Excluir: 🗑️ → itens ficam sem categoria

Sync

Botão "Sync" no admin → verifica todos os produtos → remove inativos (404/410/403). Roda automaticamente a cada 6h. Também pode ser disparado manualmente.
