Inserir Produtos

📦 Amazon — Lote (Script Local)

Varre Goldbox + 7 bestsellers (~120 produtos). Vem com categoria e link de afiliado.

  1. Clicar botão "📦 Amazon Promos" no admin (copia comando pro clipboard)
  2. Abrir terminal, colar e rodar: python3 amazon_promos.py
  3. Chromium abre, varre as páginas (~1 min), copia resultado pro clipboard
  4. Voltar ao admin → colar na textarea → Importar → Adicionar todos → Salvar no site

⚠️ Goldbox: só produtos com desconto. Bestsellers: com e sem desconto.

📦 Amazon — Individual (Bookmarklet)

Pega 1 produto por vez na página do produto. Vem com categoria e link de afiliado.

  1. Clicar bookmarklet "AM Clear" (limpa a lista)
  2. Abre a página do produto na Amazon
  3. Clicar bookmarklet "AM Copy" (extrai nome, preço, imagem, categoria, link)
  4. Repetir nos próximos produtos
  5. Clicar bookmarklet "AM Export" (copia tudo pro clipboard)
  6. Voltar ao admin → colar na textarea → Importar → Adicionar todos → Salvar no site

📦 Amazon — Lote (Bookmarklet Batch)

Varre página de busca da Amazon, pega todos os cards visíveis.

  1. Clicar bookmarklet "AM Clear"
  2. Abre uma busca na Amazon (ex: "fone bluetooth")
  3. Clicar bookmarklet "AM Batch" (pega todos os cards da página)
  4. Scroll e clicar de novo se quiser mais
  5. Clicar "AM Export" → colar no admin → Importar → Salvar

⚠️ Não funciona em bestsellers/goldbox (estrutura diferente). Categoria vem vazia — aplicar no admin.

🛒 Mercado Livre — Individual (Bookmarklet)

Pega 1 produto por vez. Vem com link de afiliado. Usa 2 abas intercalando subdomínios.

  1. Abrir 2 abas do ML (ex: produto.mercadolivre.com.br e www.mercadolivre.com.br)
  2. Clicar "ML Clear" na aba A e na aba B
  3. Na Barra de Afiliados do ML: Compartilhar → clicar "ML Copy" (repete em cada produto, intercalando subdomínios)
  4. Clicar "ML Export" na aba A → copia
  5. Clicar "ML Export" na aba B → copia
  6. Colar os dois no admin → Importar → Adicionar todos → Salvar no site

⚠️ ML Batch está no freezer (sem link de afiliado — não entra no site sem comissão).

🛍️ Shopee — Manual (aguardando API)

Ainda sem automação. Adicionar manualmente no admin: colar o link do produto na textarea → Importar → Salvar. A API Open está pendente de aprovação.

Editar Produtos

Não há edição inline no admin. Para editar um produto:

  1. No admin, localizar o produto na lista
  2. Excluir o produto (botão 🗑️ no card)
  3. Re-adicionar com os dados corrigidos (colar na textarea → Importar → Adicionar → Salvar)

Alternativa: editar o manual.json diretamente via nano/terminal e pushar.

Excluir Produtos

Individual

No admin, clicar no botão 🗑️ no card do produto → confirmar → Salvar no site.

Todos

Clicar "Remover todos" (botão vermelho) → confirmar → Salvar no site.

Automático (Sync)

O workflow sync-ml.yml roda a cada 6h e remove produtos que retornam 404/410/403. Também pode ser disparado manualmente pelo botão "Sync" no admin.

Cupons

Como adicionar

  1. Abrir cupons.json no nano
  2. Adicionar o cupom no array (ver formato abaixo)
  3. Salvar → push

Formato do JSON

{
  "nome": "15% OFF em Eletrônicos",
  "marketplace": "ML",
  "desconto": "15% OFF",
  "minima": "R$ 99",
  "maximo": "R$ 50",
  "codigo": "ELETR15",
  "categoria": "Eletrônicos",
  "validade": "até 20/10",
  "link": ""
}

Se categoria estiver preenchido, o link é gerado automaticamente (abre o site filtrado). Se vazio, usa o valor de link.

Como funciona no site

O chip "🎟️ Cupons" no header e a busca por "cupons" mostram os cupons. O botão "Resgatar →" abre o site filtrado (categoria + marketplace) — o usuário vê os produtos com seu link de afiliado e compra → comissão pra você.

Customizadas

Criadas via "➕ Gerenciar categorias" no admin (select global ou individual). Persistem em categorias.json.

  • Criar: input + botão "Criar"
  • Renomear: ✏️ → atualiza em todos os itens do batch + nas ofertas já salvas
  • Excluir: 🗑️ → itens que usavam a categoria ficam sem categoria
  • Sempre em ordem alfabética (mescladas com as fixas)

Sync

Verifica todos os produtos (ML via proxy, Amazon direto). Se a URL retornar 404/410/403, remove. Se der erro de rede, mantém.

  • Automático: a cada 6h (workflow sync-ml.yml)
  • Manual: botão "Sync" no admin → dispara via API → polling a cada 5s → timeout 30 tentativas
  • Status: laranja "Sincronizando..." → verde "Sincronizado ✓" ou vermelho "Erro no sync"

Bookmarklets

Como criar: abra uma aba em branco no Brave, clique na barra de favoritos, crie um novo favorito, edite a URL e cole o código do bookmarklet. Nomeie como quiser.
